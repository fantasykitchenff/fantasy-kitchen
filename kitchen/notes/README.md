# Kitchen notes

One file per team, named by abbreviation (`KC.md`, `SF.md`, ...), plus `NFL.md` for league-wide facts. Seeded on 2026-09-28 with about 3,500 dated facts distilled from the Fantasy football project's preseason research docs (June 24 to Aug 26, 2026). Every task reads the files for the teams it writes about before writing, and appends what it learned after. Dated, factual, backward-looking lines only. Never a projected number.

Format:

```
# KC

## Coaching and scheme
- 2026-09-15: Play-caller unchanged from 2025; pass rate over expectation top 8 through two weeks.

## Backfield
- 2026-09-22: Player X 71% snaps Week 2, first game over 65% (snap counts).

## Receivers and tight ends
- ...

## Quarterback
- ...

## Injuries and status
- 2026-09-26: Player Y (WR) Q hamstring, LP Wed/Thu, FP Fri (team report).
```
