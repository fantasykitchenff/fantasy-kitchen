# Fantasy Kitchen

Chef Hazy's fantasy football kitchen: weekly rankings, the waiver wire, start/sit, trades, and Sunday pivots, cooked from one projection model and served on the site and on X ([@FF_ChefHazy](https://x.com/FF_ChefHazy)).

The site lives in `docs/`. How the kitchen runs, and how to change it, is in [KITCHEN.md](KITCHEN.md).
